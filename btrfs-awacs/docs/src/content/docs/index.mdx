AWACS builds a persistent change index from immutable Btrfs snapshots. Git and
Watchman-compatible clients consume authenticated path invalidations; Jujutsu
can also lease the actual immutable snapshot and derive its working-copy tree
without racing the live checkout.

## Three client contracts

<CardGrid>
  <Card title="Focused Watchman">
    Changed names and authenticated clocks narrow a crawl of the **live**,
    mutable checkout. Transient directory changes must remain visible.
  </Card>
  <Card title="Native Git fsmonitor">
    Hook-v2 tokens and NUL-delimited invalidations conservatively refresh Git's
    tracked, untracked, and index state.
  </Card>
  <Card title="Direct Jujutsu scans">
    A leased read-only snapshot descriptor, authenticated cursor, and external
    input fingerprint bind a tree state to one **immutable** filesystem cut.
  </Card>
</CardGrid>

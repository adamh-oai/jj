AWACS builds a persistent change index from immutable Btrfs snapshots.
Jujutsu leases the actual immutable snapshot and derives its working-copy tree
from that exact cut instead of racing the live checkout.

## Follow one repository through four scenarios

The walkthroughs follow the same repository as its lifecycle becomes more
complex. Each step identifies **where the work runs**, **which filesystem
view is mutable or immutable**, **which durable records change**, and **which
invariants must hold** before a client can safely advance its cursor.

## Implementation status

This documentation describes the code that currently exists, including
verified regressions and missing production wiring. It does not equate a
planned schema, unused helper, environment-gated test, or architectural
proposal with a functioning production path.

:::caution[Internal schema source]
`docs/indexed-change-tracking.md` remains at its original repository path
because `src/store.rs` embeds fenced SQL blocks from that file with
`include_str!` when initializing SQLite stores. It is retained as an internal
schema input, not published here as current integration guidance.
:::

For the supported behavior, start with the
[system overview](/architecture/system-overview/), then follow the
[direct immutable-snapshot API](/integrations/direct-scan-api/) and
[Jujutsu snapshot transaction](/integrations/jujutsu-transaction/).
